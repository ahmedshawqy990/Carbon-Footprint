# 🌍 Carbon Footprint Calculator & AI Assistant (J.A.R.V.I.S.)

An intelligent desktop application built with Python and `CustomTkinter` designed to estimate personal daily and monthly carbon footprints based on three main consumption areas: Transportation, Energy usage, and Food portions[cite: 10].

---

## ✨ Features

* 🚀 **Splash Screen & UI:** Modern dark-themed dashboard styled with CustomTkinter and dynamic greeting frames[cite: 10].
* 🚗 **Transport Calculation:** Estimates CO2 emissions based on various transportation modes (Car, Bus, Train, Motorcycle, etc.) and distance in kilometers[cite: 10].
* ⚡ **Energy Options:** Supports both direct kWh input and device estimation models (appliances, tablets, lighting bulbs)[cite: 10].
* 🍔 **Food Consumption:** Tracks meal/portion factors[cite: 10].
* 🌳 **Carbon Offset & Financial Impact:** Calculates required annual tree offsets and estimates annual carbon tax costs in Egyptian Pounds (EGP)[cite: 10].
* 📊 **Smart Recommendations:** Provides personalized feedback and reduction strategies based on daily footprint thresholds[cite: 10].

---

## 🛠️ Tech Stack

* **Language:** Python 3.x[cite: 10]
* **GUI Framework:** `CustomTkinter`[cite: 10]
* **Image Processing:** `Pillow (PIL)`[cite: 10]
